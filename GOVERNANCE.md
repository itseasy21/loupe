# Governance

Loupe is Apache-2.0 and community-led. Core maintainers steward the trace format, local-first debugging capabilities, and release quality.

Core replay, causal tracing, CLI workflows, and local storage remain free. Paid team or enterprise work may add hosted collaboration features, but must not gate the core debugging loop.

Major technical decisions should be documented in `docs/` and reviewed publicly once the repository is public.
